# 打印素材实测记录

> 评分项要求“有效边长测量与记录正确”，所以实测值要留在这里，不能只填进 `config.py` 就完事。
> 打印后**立刻**量、立刻填；量具写清楚（直尺/游标卡尺），量两次取一致值。
> 量的是 **Tag 黑框外边的外边长**（不是整张纸、也不含外部白边）；棋盘格量 **单个方格边长**。

| 项 | 值 |
| --- | --- |
| 打印设置 | **不是 100%**：由实测验尺反推为“适应页面 / 铺满宽度”——整幅 1200 px 印成约 201 mm（A4 宽 210 mm），折算 0.1675 mm/px |

| 校验尺实测 | 该图**没有**页脚校验尺（手机屏版不含尺）→ 改用**黑框边框厚度**交叉验证：应为 1 个单元 ≈ **17.3 mm**（= 138.0 / 8） |

## 2. AprilTag（实际使用：`assets/patterns/practice/apriltag_36h11_id0_phone_screen.png` 印到 A4）

| 项 | 标称 | 实测 | 量具 |
| --- | ---: | ---: | --- |
| 家族 / ID | tag36h11 / ID 0 | tag36h11 / ID 0（与 `config.TARGET_ID` 一致） | 目视核对 |
| 黑框外边外边长 s | 100.0 mm | **横 138.0 mm / 竖 138.0 mm**（两向相等 ⇒ 未被拉伸） | 直尺 |
| 含白边整张 | 125.0 mm | 172.5 mm（= 138.0 × 10/8，推算未单量） | — |

> 说明：这一页用的是**手机屏版**图（`phone_screen`），它没有页脚校验尺，所以改用
> **边框厚度**做交叉验证：黑框边框厚度应为 1 个单元 = 138.0 / 8 ≈ **17.3 mm**。
> 该图最外圈是 1 单元白边（程序角点精测：黑框 **824.1 × 824.2 px**，占画布 1200 px 的 68.7% = 8/10），
> 因此**量到的黑区外沿就是黑框外边**，不要再乘 8/10。
> **防拉伸核对（已做）**：横边与竖边都量得 **138.0 mm**，与"整幅按宽铺满 A4 可打印宽 201 mm、
> 0.1675 mm/px × 824 px = 138.0 mm"完全一致。若打印程序纵向也拉满整页，竖边会量到 ≈173 mm；
> 实测两向相等 ⇒ 是**等比缩放**，满足手册"避免拉伸"的要求。
> 138 mm 略高于手册建议的 80~120 mm：手册写的是"建议"，边长按实测填即可，偏大对检测与精度有利。

→ 实测值已填入 `config.py: TAG_EDGE_MM = 138.0`
